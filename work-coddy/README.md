# work-coddy · 实时 IDE 工作台

> 在 WorkBuddy 结果区「网页」页签内，为当前对话与工作空间拉起一个实时同步的轻量 IDE：左侧写代码、跑命令、设断点，右侧继续与 WorkBuddy Agent 对话。无需安装额外 IDE，单 Node 进程，离线可用。

| 项 | 值 |
| --- | --- |
| 形态 | WorkBuddy Skill（`name: work-coddy`） |
| 版本 | 1.1.3 |
| 运行位置 | WorkBuddy 内置浏览器（结果区「网页」页签） |
| 依赖 | Node.js ≥ 18、npm；Monaco 资源首次启动自动准备 |
| 网络 | 仅绑定 `127.0.0.1`，不访问公网即可运行 |

---

## 1. 它解决什么问题

三类常见摩擦：

1. **窗口切换**：在 WorkBuddy 里让 Agent 生成代码，却要跳到另一个 IDE 才能查看、修改、运行。
2. **工具过重**：只是改一个脚本、跑一次命令，却要启动完整 IDE、等待索引与扩展加载。
3. **验证断点**：AI 生成的代码想立刻单步看变量，但缺少就地调试手段。

本 Skill 把「文件树 + 编辑器 + 终端 + 断点调试器 + Agent 对话」压进 WorkBuddy 的一个页签，复用宿主已鉴权的 Agent 会话，不新建登录态、不安装独立 IDE。

## 2. 快速开始

### 由 Agent 部署（推荐）

在 WorkBuddy 对话中说：

```
帮我为当前工作区打开实时 IDE
```

Agent 会按 `SKILL.md` 的流程：确定 `<WORKSPACE>` → 发现 Agent 网关端口 → 后台启动服务 → 在结果区「网页」页签打开 `http://127.0.0.1:<IDE_PORT>`。首次成功后会回写 `SKILL.md` 的「本机设置」缓存，后续调用不再重复探测。

### 手动启动

```bash
WB_IDE_ROOT=<WORKSPACE> \
WB_IDE_PORT=<IDE_PORT> \
node <SCRIPTS>/server.mjs
```

Windows 可双击 `scripts/start.cmd`，并把工作区路径作为第一个参数传入：

```
start.cmd <WORKSPACE>
```

启动后以终端打印的 URL 为准（端口占用时会自动递增）。**停止**：结束该 Node 进程即可，无守护进程、无开机自启。

> 完整环境变量、网关发现规则与协议契约见 [`references/TECHNICAL-MANUAL.md`](references/TECHNICAL-MANUAL.md)。

## 3. 功能一览

| 能力 | 说明 |
| --- | --- |
| 文件树 | 目录展开/折叠（多级）、新建文件、刷新、选中高亮 |
| 编辑 | Monaco 多标签、语法高亮、Ctrl+S 保存、Ctrl+P 快速打开、外部修改检测与同步 |
| 搜索 | 全局文本搜索（Ctrl+Shift+F），结果点击跳转行 |
| 终端 | 命令流式输出、↑↓ 历史、清屏、Git 状态、单文件运行 |
| 图形断点调试 | gutter 断点、F5 启动/继续、F10 单步、F11 步入/步出、调用栈、局部变量、当前行高亮、调试控制台（**仅 JavaScript**） |
| 插件 | 本地 `.mjs` 插件、Ctrl+Shift+P 命令面板（内置命令 + 插件命令）、插件页签 |
| Agent 对话 | 复用 WorkBuddy 当前会话，实时事件流 + 最近 16 条会话历史同步 |

**快捷键**：`Ctrl+S` 保存 · `Ctrl+P` 文件 · `Ctrl+Shift+P` 命令 · `Ctrl+Shift+F` 搜索 · `Ctrl+Enter` 运行 · `F5/F10/F11` 调试。

## 4. 适合谁用

| 人群 | 为什么适合 | 典型任务 |
| --- | --- | --- |
| **轻量编程者 / 脚本作者** | 单文件或少量文件即可完成任务，不需要项目级索引与构建链 | 数据清洗、批处理、自动化脚本、一次性工具 |
| **编程新手与学生** | 编辑器、运行、断点、AI 讲解在同一屏，降低环境配置门槛；断点可视化便于理解执行流程 | 语法练习、算法入门、跟着教程改代码 |
| **非专业开发人员** | 主业不是软件工程，需要 AI 把想法直接变成可运行代码并就地验证 | 科研人员跑分析脚本、办公自动化、表格/文档批处理、问卷统计 |
| **WorkBuddy 生态内用户** | 不想离开当前工作台，也不愿为轻量任务安装或切换独立 IDE | Agent 生成代码后立刻查看、微调、运行 |
| **需要边写边问的人** | 右栏对话与左栏代码共享同一工作区，Agent 可直接读写当前文件 | 让 AI 解释报错、重构小段代码、补注释 |
| **教学 / 演示 / 结对讲解** | 一个页签内同时展示代码、执行结果与讲解过程 | 现场演示、代码走查、远程辅导 |
| **快速验证想法的人** | 服务秒级启动、无需建工程 | 验证一段 API 调用、试一个正则、跑个最小复现 |

> 对**以单文件或小型 JS 实验为主的专业开发者**，本工具同样适用；判断标准不是身份，而是任务规模与工程化要求（见下一节）。

## 5. 不适合谁用

以下判断基于实际能力边界，而非使用者身份：

| 人群 / 场景 | 不匹配的原因 | 建议替代 |
| --- | --- | --- |
| **以工程化交付为主的开发者与团队** | 缺少完整语言服务（LSP/IntelliSense）、类型检查、重构、ESLint 集成、测试运行器、多根工作区与 Git 图形化 | CodeBuddy CN IDE、VS Code、JetBrains 系 |
| **中大型或多语言工程** | 文件树深度上限 4、搜索上限 200 条；图形断点调试仅支持 `.js/.mjs/.cjs`，TypeScript 需先编译，Python/Java/C++/Go 只能终端运行 | 完整 IDE + 对应语言调试器 |
| **依赖扩展生态的人** | 不能安装 VS Code 扩展；仅支持本地 `.mjs` 插件与命令注册 | 完整 IDE + 扩展市场 |
| **前端 / 移动端 / 嵌入式 / 远程容器调试** | CDP 调试器面向 Node 进程，不提供浏览器 DevTools、设备连接、容器或 SSH 远程开发 | 浏览器 DevTools、专业 IDE 远程开发 |
| **要求稳定长会话与独立 Agent 会话的人** | Agent 对话复用 WorkBuddy **当前主会话**，主会话忙碌时消息排队；服务随宿主会话结束需重新启动 | WorkBuddy 主对话，或完整 IDE 的独立 Agent 面板 |
| **协作、评审与发布流程** | 无 PR、代码审查、分支管理、CI 集成 | Git 平台 + 完整 IDE |
| **对性能与确定性要求高的生产环境** | 面向本地轻量交互设计，未做大规模仓库索引、并发会话隔离与长时间稳定性优化 | 专业开发工具链 |

**边界人群**：若你的工作是中小型 JavaScript 项目、且不需要重构与类型检查，本工具可以覆盖日常编辑与调试；一旦需要项目级导航、多人协作或跨语言调试，应切换到完整 IDE。

## 6. 与完整 IDE 的对比

| 维度 | work-coddy | 完整 IDE（CodeBuddy CN / VS Code） |
| --- | --- | --- |
| 启动成本 | 单 Node 进程，秒级，无索引 | 应用启动 + 工程索引 + 扩展加载 |
| 所在位置 | WorkBuddy 窗口内的一个页签 | 独立窗口 |
| 语言服务 | Monaco 基础高亮与补全 | 完整 LSP、类型检查、重构 |
| 调试 | Node/JS 图形断点调试 | 多语言调试、条件断点、监视表达式 |
| 扩展 | 本地 `.mjs` 插件 + 命令 | 扩展市场生态 |
| Agent | 复用当前 WorkBuddy 会话 | 自带独立 Agent 会话 |
| 适用规模 | 单文件 / 小项目 / 临时实验 | 中大型工程、团队协作 |

## 7. 限制与风险

- **共享会话**：从 IDE 发出的消息会进入 WorkBuddy 主对话；主会话正忙时排队，回复可能延迟。
- **调试语言**：仅 JavaScript。多语言升级路径见技术手册 8A。
- **安全**：服务只绑定 `127.0.0.1`；`/api/exec` 可执行任意 shell 命令，等价于本地终端，请勿改绑外部地址。插件在服务端进程内动态 `import`，等价于本地代码，只加载可信来源的 `.mjs`。
- **资源上限**：文件树深度 4 层、搜索 200 条、单文件读取 1 MiB、命令超时 120 秒——均为保持轻量的有意约束。
- **生命周期**：服务无守护进程，宿主会话结束后需按第 2 节重新启动；`SKILL.md` 的「本机设置」缓存可加速复用，但每次使用前必须校验。
- **不承诺**：完整 VS Code 工作台、扩展市场、图形化断点调试以外的语言支持。

## 10. 常见问题

**打开链接提示连接被拒绝？** 服务未运行或端口已递增。按第 2 节重新启动，以终端打印的 URL 为准。

**右栏没有回复？** 确认 `/api/state` 中 `connected: true`；主会话忙碌时消息会排队。可点「同步会话」拉取最近历史。

**断点不命中？** 确认文件是 `.js/.mjs/.cjs`、断点行是可执行语句；`--inspect-brk=0` 会在入口先暂停一次，点「继续」后才会命中用户断点。

**插件没出现？** 检查 `.mjs` 是否位于 `<WORKSPACE>/.wb-ide/extensions/` 且导出了 `activate`；重启服务后生效。

**发布到 Skill 市场前要做什么？** 把 `SKILL.md`「本机设置」表所有值恢复为 `未设置`，保证包体与具体电脑无关。
